# 全息棱锥播放器page
在线使用：<https://yoink-gb6.github.io/KeepAlive/> （支持离线使用）


## 功能

- [x] 自定义持续时长与轮播内容

可导入
- [x] 3D 模型（.glb）
- [x] 照片
- [x] 照片自动抠图
- [x] 视频
- [x] 四分屏视频
- [x] 背景音乐
- [x] 旋转相册
自动处理
