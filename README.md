# 全息棱锥播放器page

## 原理
**佩珀尔幻象**（Pepper's ghost）：透明的斜面会把一部分光反射进眼睛，同时又能透过它看到后面，所以反射出的画面像悬在空中。棱锥的四个面与屏幕成 45°，各自把屏幕上对应的一块画面反射成竖立的虚像，四个虚像重合在棱锥中心。它常被叫作"全息投影"，但并不是真正的全息术（holography），所以只有四个固定视角，而不是连续的 360°。
